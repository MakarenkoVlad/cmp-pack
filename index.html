CMP

v0.2.3 · 2026-09-26 · Minecraft 1.21.1 · NeoForge 21.1.251 · 45 mods

Download CMP.zip

A Prism Launcher instance. You import it once; after that the pack updates itself.

Install

  1. Get Prism Launcher from prismlauncher.org and sign in with your Microsoft account.
  2. Import CMP. In Prism click Add Instance → Import, paste the link (Copy link for Prism above) or pick the downloaded CMP.zip, then OK. You can also drag CMP.zip onto the Prism window.
  3. Launch CMP. On the first start a small updater window downloads the mods. The CMP server is already in your multiplayer list.
  4. Link your Discord. The first time you join, the server shows you a code. Send it to the CMP bot in a Discord direct message, then join again.

Updates

Nothing to download. Every time you press Launch, the updater fetches whatever changed since your last start, usually in a few seconds. If the server updates while you are playing, close Minecraft and launch it again. If the updater asks to change the NeoForge version, click Update.

If something goes wrong

"Mod mismatch" or missing mods when joining
Your game started before the update went out. Close Minecraft and launch it again.
The updater can't connect
Click Continue to play with the files you have; it tries again on the next launch.
Stutters or out-of-memory crashes
The instance may use up to 6 GB of memory. Change it in Prism under Edit → Settings → Java; keep at least 4 GB.
Coming from the old .mrpack
Import CMP.zip as a new instance. To keep your keybinds and video settings, copy options.txt from the old instance's minecraft folder into the new one, then delete the old instance.
Another launcher
Only Prism and MultiMC run the updater before the game starts. Anywhere else you would reinstall the pack by hand after every update, so please use Prism.
